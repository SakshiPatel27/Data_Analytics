# Epic Games Sales Analysis Dashboard

## Overview
This Tableau dashboard provides comprehensive analysis of Epic Games and video game sales data. The analysis covers game genres, publishers, sales trends, platform performance, user ratings, and critical reviews across global markets from 1999 to 2015.

## Key Metrics

| Metric | Value |
|--------|-------|
| **Total Global Sales** | 8,920 (in millions USD) |
| **North America Sales** | 4,403 |
| **Europe Total Sales** | 2,425 |
| **Japan Sales** | 1,297 |
| **Other Country Sales** | 791.3 |
| **Average Critic Score** | 68.97/100 |
| **Average User Score** | 6.87/10 |

## Dashboard Components

### 1. **Geographic Sales Distribution**

#### Sales by Region
- **North America**: $4,403M (49.4% of total) - Dominant market
- **Europe**: $2,425M (27.2% of total) - Second largest market
- **Japan**: $1,297M (14.5% of total) - Strong Asian presence
- **Other Countries**: $791.3M (8.9% of total) - Emerging markets

#### Regional Insights
- North America drives nearly half of all global game sales
- Europe represents a substantial second market
- Asia-Pacific (Japan) shows strong gaming adoption
- International markets remain underexploited

### 2. **Genre Analysis**

#### Genre Distribution by Sales and User Count

**Top Genres by Sales:**
- **Action**: 1,745 games - Highest sales volume
- **Sports**: 1,332 games - Strong market segment
- **Shooter**: 1,053 games - Third major category
- **Role-Playing**: 934 games - Growing segment
- **Platform**: 828 games - Classic gaming segment
- **Misc**: 803 games - Diverse offerings
- **Racing**: 729 games - Steady performer
- **Fighting**: 447 games - Niche category
- **Simulation**: 390 games - Specialized games
- **Puzzle**: 243 games - Casual gaming
- **Adventure**: 238 games - Story-driven games
- **Strategy**: 175 games - Complex gameplay

**Key Insights:**
- Action games dominate the market
- Sports games show consistent popularity
- Shooter genre has explosive growth
- Niche genres (Fighting, Simulation, Strategy) remain smaller

### 3. **Publisher Market Analysis**

#### Top Publishers by Game Count
- **Electronic Arts**: 1,356 games (Largest publisher)

#### Publisher Insights

### 4. **Platform Performance**

#### Global Sales by Platform
- **PS2**: Highest sales volume
- **X360**: Strong Microsoft presence

- **Wii**: Nintendo's motion control success
- **DS**: Handheld gaming dominance

#### Top Games by Platform
- **FIFA 14**: 16.48M sales
- **Need for Speed**: Top racing franchise
- **Madden NFL**: American football dominance
- **LEGO Marvel**: Successful franchise
- **Ratatouille**: Movie tie-in success

### 5. **Quality Metrics**

#### Critic vs User Scores
- **Average Critic Score**: 68.97/100
- **Average User Score**: 6.87/10
- Discrepancy indicates varied perspectives between critics and users

#### Top Rated Games
- **Call of Duty: Modern Warfare 3**: 20,053 sales
- **The Witcher 3: Wild Hunt**: 24,807 users
- **The Elder Scrolls V: Skyrim**: 15,189 users
- **Grand Theft Auto V**: 15,124 users
- **Fallout 4**: 13,489 users

### 6. **Sales Trends Over Time**

#### Year-wise Global Sales (1999-2015)
- **1999-2005**: Steady growth phase
- **2005-2009**: Exponential growth period
- **2009-2012**: Peak sales period (658.9M in peak year)
- **2012-2015**: Stabilization and fluctuation
- Peak sales observed around 2008-2009 period

#### Trend Analysis
- Game sales increased significantly with console generation shifts
- PS2 era (2000-2005) drove massive growth
- HD console generation (PS3/X360) maintained high sales
- Recent years show market saturation with cyclical patterns
